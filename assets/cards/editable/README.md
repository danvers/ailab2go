# Editable A6 card deck — raw layers

Generated by `bash setup/tools.sh cards --editable`. Re-running overwrites
these files — save your own edits under a new name.

| File | What it is |
|---|---|
| `front_NN.png` | front background per card, 300 dpi — carries the glitch look (glow, scanlines, colour bars, accent bar) |
| `icon_NN.png` | the emoji icon, transparent |

Card order: stations 1–6, then discussion cards 1–6. The accent colours
are `ACCENT_STATION` / `ACCENT_DISCUSS` in `setup/make_cards.py`.

## Photoshop / Illustrator / Affinity

Use `front_NN.png` as the background layer and set your own type on top
(Helvetica Neue, Bold for the title). Brand colours `#400b67` / `#c32683`.

## Print-ready / vector

Open `setup/cards_de.html` (or `_en`) in a browser and print to PDF — the
PDF keeps the text as editable vector type. Double-sided: flip on the
**short** edge.
